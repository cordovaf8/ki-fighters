# Transformation artwork

Generated with the built-in image_gen tool using each character's existing roster portrait as the identity and style reference. Original sheets live in each character folder as `transformations.png`; `build-transformation-assets.mjs` slices them into individual pose files and regenerates the image manifest.

## Shared prompt

Create a production game sprite sheet, five columns and four rows, twenty equal cells. Transparent background, no labels, grid lines, external aura, or projectiles. Full body in each cell, consistent size and baseline, padding on all sides. Match the reference's anime pixel-edged illustration style and face right in three-quarter view. First two rows show form one; last two rows show form two. Each form has ten poses: idle guard, alternate breathing idle, palm shot, charged palm shot, cupped-hand beam, straight punch, hurt recoil, crossed-arm block, fists-at-hips power-up, and deep-stance cupped-hand special. Preserve identity and correct anatomy in every pose.
